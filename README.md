# A5VM

Экспериментальный эмулятор старых машин для слабых ARMv7-устройств. Первый
целевой хост — iPhone 4S (Apple A5, iOS 6), а первая гостевая машина —
минимальный 8086 PC.

Проект вырос из идеи `RetroVM`, но получил короткое рабочее имя `A5VM`.

## Текущий этап

Сейчас реализован первый вертикальный срез:

- 1 MiB памяти с 20-битным адресным пространством 8086;
- регистры 8086, сегментация и reset state;
- интерпретатор базовых MOV/ADD/SUB/CMP/JMP/Jcc/PUSH/POP/HLT;
- минимальная программа-демонстрация;
- unit tests без сторонних библиотек.

Это пока не полноценный QEMU и не загрузчик MS-DOS: BIOS, PIC/PIT, VGA,
клавиатура, диски и iOS frontend будут добавляться отдельными этапами.

## Сборка на Windows

Нужен LLVM Clang. Если он установлен в стандартный каталог, выполните:

```powershell
.\tools\build.ps1
```

После этого:

```powershell
.\build\a5vm-demo.exe
.\build\a5vm-tests.exe
```

## План

1. Завершить тестируемое ядро CPU и память.
2. Добавить BIOS-загрузку boot sector и VGA text mode.
3. Подключить floppy image и добиться приглашения `A:\>` в MS-DOS.
4. Сделать headless CLI и только затем iOS 6 frontend.
5. После стабильного interpreter исследовать ARMv7 JIT.

Образы ОС и ROM-файлы не входят в репозиторий.
